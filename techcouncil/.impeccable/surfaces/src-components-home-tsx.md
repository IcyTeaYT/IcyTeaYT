# Home surface brief

Scope: the single-page TIS Tech Council site (Home.tsx). Mode: Persuade.
Audience: TIS students, staff, parents. Job: understand the council, trust it via real work, send an idea.
Constraints: dark-first; Clash Display + Inter + JetBrains Mono (code voice); motion-rich but reduced-motion safe; no invented data.
User decisions: round 1 (critique) petal colours lead; compact honest founders row; Projects straight after hero. Round 2 (user steer): "techy, like code, a mix between the first version and the petal version, not over the top" — brings back the dot grid with cursor light, one blue light, the marquee, the bento, cyan as the electric accent, and code windows; content stays honest.

## Direction contract
THESIS: A student tech council's own terminal, in the school's colours. The four logo petals carry brand and action; a restrained code layer (mono paths, terminal lines, real code windows, a cursor-lit grid) says "we build software". Refuses fake dashboards, invented stats and gradient text.
OWN-WORLD: Logo-navy ground (#0A0F17) with a faint 28px dot grid; paper-white type; petal orange for actions; petal cyan as the electric light (cursor grid, caret, trace highlights, path accents); petals as syntax colours in editor windows (window dots orange/maroon/teal); JetBrains Mono for paths, terminal lines, data and code only; hairline rules; one soft blue light in the hero; glass only on the nav pill.
STORY: See what the council is (headline with a live cursor), see the live launch status in a terminal line, scroll past the ideas marquee to the real TISMUN platform, learn what the council does through real code and the Idea to Ship pipeline, meet the founders, send an idea and get a 201 back.
FIRST VIEWPORT: Left: headline "Student-built tech for a smarter TIS." with a blinking cyan caret; mission line; orange "Suggest an idea" + text link; a two-line terminal status "~/tech-council $ status / TISMUN 2026 goes live in …". Right, cropped: the logo mark over circuit traces and a dot grid that lights cyan under the cursor. Motto rail at the bottom.
FORM: Code-led; user-pinned blend of the two previous builds (no concept roll). Signature interaction: petals lean toward the cursor while the grid and traces light up around it; code windows run an execution trace.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
