# Awesome DESIGN.md

Vendored from [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) (MIT, see `LICENSE`).

Each brand has its own folder: `design-md/<brand>/DESIGN.md`. A DESIGN.md holds the brand's tokens (color, typography, spacing, radius, elevation), component rules, and the reasoning behind them. The `README.md` next to it only links to previews on getdesign.md.

## How to use

1. Pick the brand that is closest to what the user asked for. If they didn't name one, pick by feel: for example `linear.app` or `vercel` for crisp dev tools, `apple` or `tesla` for premium minimal, `notion` or `claude` for warm editorial, `spotify` or `nike` for bold consumer.
2. Read `design-md/<brand>/DESIGN.md` in full.
3. Build to that spec: use its tokens as CSS variables and follow its component and layout rules. Stay inspired by the brand rather than copying it: use the user's own name, content and logo, never the brand's.
4. To blend two brands, take the structure and type from one and the color and accent treatment from the other.
