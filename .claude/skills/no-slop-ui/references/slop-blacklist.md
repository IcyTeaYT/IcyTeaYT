# Slop blacklist → what to do instead

These are defaults, not crimes. If the brief explicitly asks for one, do it well. Otherwise, choose something specific to the subject. `scripts/slop_check.py` detects most of them.

## Layout
| Tell | Instead |
|---|---|
| Feature grid: icon + title + two lines, ×3 | Show the product doing the thing; or an index list with real specifics |
| Bento with equal tiles and icons | Bento only when tiles differ in importance; each tile holds a real UI fragment or image |
| Hero = huge number + small label + gradient accent | Hero shows the most characteristic thing in the subject's world (a working form, the product, a photo) |
| Everything centred | Left-aligned, asymmetric grid; centre one short closing moment |
| Announcement pill above the hero ("Introducing…") | Only for real news, with a date |
| Logo wall of fake logos | Only real partners/users, with permission |
| Same section rhythm repeated | Vary pattern, height and density section to section |

## Type
| Tell | Instead |
|---|---|
| Tracked ALL-CAPS eyebrow over every heading | Delete it; the heading says what the section is |
| "01 — About" numbering | Numbers only for real steps or timelines |
| One word in italic/colour/gradient inside a headline | Let the whole line carry it; emphasis through size and space |
| Monospace micro-labels for decoration | Mono only for code and real data |
| "A · B · C" meta strings | Separate elements, or fewer items |
| Heavy 800 weight at display sizes | 500–600 with tight tracking |

## Colour
| Tell | Instead |
|---|---|
| Purple→blue / pink gradients | Luminance (white alpha) or the subject's own colour |
| Tailwind indigo/violet accent | A colour with a reason, or none |
| Terracotta on cream | Only if it is literally the brand |
| Acid green / vermilion single accent on dark | Light as the accent; colour for meaning |
| `#0B0B0B`/`#111` posing as black | `#000`, or a brand dark with a reason |
| Blurred colour blobs behind the hero | Light with a source (top glow, the product's own glow) |

## Components
| Tell | Instead |
|---|---|
| Same radius and same soft grey shadow on every card | Radius by level; depth by surface luminance + lit edge |
| Glassmorphism everywhere | Glass for the nav and overlays only |
| Icons in tinted circles | Real product detail, or no icon |
| Emoji / ✨ sparkles as icons | A specific icon, or nothing |
| "→" appended to every button | Label says what happens; icon only for external/download/play |
| Testimonials from "Sarah K., CEO" | Real quotes with real names, or leave it out |

## Motion
| Tell | Instead |
|---|---|
| Fade-up on every section | One orchestrated hero entrance + 1–2 meaningful moments |
| Hover lift + shadow on every card | Light responds (spotlight/edge); lift only for draggable/pickable things |
| Parallax on everything | Scroll-linked motion only when it explains (a product assembling, a state changing) |
| Bouncy springs on text | Soft ease-out; springs for controls |
| Autoplaying marquee of buzzwords | Nothing, or a marquee of real content |

## Copy
| Tell | Instead |
|---|---|
| Unlock / Elevate / Seamless / Supercharge / Empower / Next-gen | Plain verbs: what it does, for whom |
| "Welcome to X" | What X is or does, in one line |
| "Get started today" / "Learn more" / "Submit" | The exact action: "Share idea", "See the projects", "Send application" |
| Lorem ipsum, Acme, John Doe | Real content; ask if unknown |
